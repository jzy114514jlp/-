# 别漏事

把校园群公告、招募海报和办事通知整理成可核对的行动卡。项目为 Edge Future 2026 黑客松「科技向善」赛道准备。

## 已完成的功能

- 粘贴通知文字，提取主题、活动时间、地点、参与方式、报名截止和待办。
- 上传通知截图，在浏览器内用 Tesseract.js 识别中文文字；识别结果自动进入行动卡。
- 每个提取字段显示原文依据。原文没写的报名截止时间明确标为“未提及”。
- 修改识别字段、勾选待办、展开原文核对。
- 对写明年份和日期的活动导出 `.ics` 日历文件，附活动前一天提醒。
- 内置用户提供的黑客松通知样例，便于现场演示。

图片和通知文字都在浏览器内处理，应用没有账号、数据库或上传接口。首次使用截图识字需要联网下载 OCR 模型。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

浏览器打开开发服务器显示的本地地址。构建检查：

```bash
npx tsc --noEmit
npm run build
```

由队友在另一台电脑上演示时，请按 [现场演示交接指南](SHOWCASE.md) 提前安装和排练。Windows 电脑也可以双击 `start-demo.cmd` 启动。

## 现场演示建议

1. 点击“试用黑客松通知”。
2. 指出活动时间、地点、个人或组队参与方式已经提取。
3. 指出报名截止时间没有出现在原文中，因此行动卡不会猜测。
4. 勾选报名动作，演示修改字段和导出活动日历。
5. 准备一张字迹清晰的真实通知截图，展示识字流程；先下载好模型，避免现场网络波动。

## 处理边界

当前版本采用浏览器 OCR 加可解释的中文规则提取，不调用云端大语言模型。复杂排版、模糊截图、口语化日期和跨句信息可能需要手动校正。日历导出只支持带明确年份、月份和日期的活动安排；导入前仍需核对原通知。
